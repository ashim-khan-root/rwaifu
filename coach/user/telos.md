# TELOS -- Mission, Goals, Beliefs, Wisdom

## Mission
Become an independent AI Engineer. Build AI-powered products that generate real income and solve real problems -- for myself and for clients.

## Goals
1. Become a skilled prompt/AI engineer -- master structuring, chaining, RAG, tool-use, evals
2. Ship a product that earns independent revenue (SaaS, tool, or platform)
3. Launch and grow freetoolz.in (traffic, backlinks, directory listings, SEO)
4. Make aslielectronic.com a working e-commerce site with actual customers
5. Automate workflows with n8n, Supabase, and scripts

## Beliefs
- AI should magnify human capability, not replace it
- Build-first > plan-first. Ship fast, iterate.
- Local-first when practical (Ollama, local models) -- keep control
- Automation > manual. If you do it twice, script it.
- Reusable systems > one-off fixes

## Wisdom (things I've learned)
- The biggest gap is between knowing and shipping. Close it.
- Context quality matters more than model size.
- Multiple small income streams beat one fragile one.
- SEO is a long game -- consistency compounds.
- Don't over-engineer. Practical > perfect.

## Mental Models I use
- **Build-first learning:** Quick read, then build. Learn by doing.
- **Second brain:** offload context to the coach, focus on decisions.
- **Income diversification:** never rely on one source.
- **Automation leverage:** spend time once to save time forever.
- **Local-first:** own your data, own your infrastructure.

## Narratives that drive me
- From security engineer to independent AI engineer
- From one salary to multiple income streams
- From user of AI tools to builder of AI products
